# ONO ACADEMY Website MVP

학원 운영 + 학습관리 + AI 자동화를 하나로 묶는 **ONO ACADEMY** 홈페이지 MVP입니다.

## 현재 포함된 내용
- 랜딩 페이지
- 학원 운영 대시보드 콘셉트
- 학생 / 출결 / 오답 / 상담 / 통계
- AI 홍보실
- AI 수업 복습
- 예시 요금제
- 반응형 모바일 레이아웃

## 실행
`website-mvp/index.html` 파일을 브라우저에서 열면 바로 확인할 수 있습니다.

> 현재는 UI/사업 콘셉트 검증용 정적 MVP이며 로그인·DB·결제·문의 폼은 연결되어 있지 않습니다.

## 2026-08-23

- **fix: Supabase API 인증 및 DB 접근 권한 오류 대응**
  - `Invalid API key (401)` 오류 원인 점검
  - `permission denied for table ... (42501)` 오류 확인
  - API Key 종류 및 Streamlit Secrets 연결 상태 점검
  - 앱 로직이나 데이터 손상이 아닌 DB 인증 역할 및 접근 권한 문제로 분리
  - 연결 설정 정상화 후 서비스 복구

- **fix: 일부 사용자 ReadError 확인**
  - 일부 사용자 환경에서 `ReadError: [Errno 11] Resource temporarily unavailable` 간헐 발생
  - 전체 서비스 장애와 별개의 일시적 읽기/리소스 오류로 분류
  - 재시도 로직 및 공통 예외처리 개선 검토

- **ops: 계정 복구 및 장애 대응 기준 정리**
  - 로그인 문제 발생 시 신규가입보다 **비밀번호 재설정 요청**을 우선하도록 운영
  - 개별 사용자 오류와 전체 서비스 장애 처리 절차 분리
  - 담당자 화면에서도 계정 복구 요청 확인 및 처리 가능
